# Scripts

- `berka/` — **scorecard pipeline** on the real Berka bank data: load, features, fit, score, validate.
  See `berka/README.md`. Run everything with `npm run scorecard`.
- `run_query.js` — ad-hoc query runner: `node scripts/run_query.js -e "SELECT ..."` or a `.sql` file.

The previous version (synthetic data generator and SQL scripts 00–07) is kept in `archive/previous_version/`.
